# Voltage Regulator

Es un regulador de tensión con limitador de corriente, ambos se puede configurar. El rango es bastante amplio, diseñado para 0V-30V, y 0A-5A. Tiene control de estos parámetros a través de un microcontrolador (ATMega328P).

# Características
- Seguidor de tensión
- Limitador de corriente
- Preset digital
- Transferencia/configuración con conexión serial
